# 哔咔桥Web管理后台

自0.7.6加入的Web网页管理后台，可轻松图形化管理各种配置。  

使用和登录App一样的账号密码登录即可。  

主页做了个等级系统，根据你库中的漫画数量评级(滑稽)  
祝早日成为阅本无数的绅士淑女！  
![等级设定](/tools/Documentation/img/等级设定.png)  

快捷操作部分可立即触发和LRR元数据的同步  
此处为全量同步操作，当数据过多时可能需要较长时间完成。

后台访问根路径不会自动跳转，避免他人误入，需要手动加 `/ui` 路径  
使用配置向导中设置的哔咔桥地址后加 `/ui` 访问即可。
